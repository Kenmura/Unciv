### T334 Two client instances on one machine become the same player: give each instance its own identity (profile) so multiplayer can be tested locally
- State: Needs-Review [Claude]
- Depends: none
- Source: Owner report 2026-10-30: launching 2 instances to test multiplayer makes them the same user. Cause found: Unciv.Godot/Assets/UserPaths.cs Identity = user://identity.key (one shared file per OS user), also shared: client settings (player name), saves, autosaves
- Fixtures: none
- Deliverables: A profile mechanism: --profile NAME on the command line (and UNCIV_PROFILE env var) selects a separate identity.key, settings, saves and autosaves under user://profiles/NAME/ (no profile = today's location, so existing players keep their identity); the in-game player name and a visible profile label so two windows are distinguishable; a launch helper or documented command for 'second instance' in GODOT.md and the lobby docs; two-instance scenario in the harness (host + join as two profiles on one machine) proving two distinct PlayerKeys, separate saves, and that one instance's settings do not change the other's; tests for the path resolution (no path traversal in NAME)

Files: Unciv.Assets/Settings/UserProfile.cs (UserProfile.Resolve, ProfileFiles), UserPaths uses ProfileFiles. Profile folder user://profiles/NAME/ holds identity.key, host-key.pfx, known-hosts.json, last-join.txt, settings.json (player name), saves (autosaves included), hosted. No profile = exactly the old paths (tested: UserProfileTests, TwoProfilesTests.ExistingPlayer_KeepsTheirIdentity...). Window title "Unciv - NAME", "Profile: NAME" line on the main menu (only with a profile, so default goldens unchanged), and the lobby display name is the profile name. Help text: join screen and host Network tab (goldens host-screen network/network-address, join empty/wrong-password regenerated) plus GODOT.md "Two instances on one computer". Command: `Unciv.x86_64 -- --profile=friend` or `UNCIV_PROFILE=friend Unciv.x86_64` or `godot --path Unciv.Godot -- --profile=friend`.
