      - Model (Unciv.Assets/Settings/GraphicsModel.cs, pure, 100% line cov): GraphicsQuality Low/High/Ultra, GraphicsPreset table {shadows, tonemap, glow, msaa, ssao, ssr, shaderTier, farZoom, exposure, ambient}, Effective level, Startup/restart flow, Note texts, RestartArgs.       - Restart flow (GraphicsRuntime + App._Ready, before anything is built): Ultra on a non-Forward+ renderer stores rendererPending=forward_plus then OS.SetRestartOnExit(--rendering-method forward_plus, original args kept). Next start: renderer matches -> marker cleared; renderer does not match (or Forward+ on llvmpipe/lavapipe/SwiftShader) -> ultraFailed stored, Ultra shows High, no further restart. Picking Ultra again in the picker clears the flag (one attempt per explicit choice). Leaving Forward+ for Low/High restarts back to gl_compatibility once with the same marker guard; Low/High never force a restart on mobile/other renderers.
      - MapView.ApplyGraphics sets Environment (tonemap, exposure, ambient, glow, SSAO, SSR), sun shadows and Viewport.Msaa3D; GameScreen applies it on every settings change. Levels feed the C085 caps: UnitLod.IsFar(zoom, preset.FarZoom): Low 22 (unchanged), High 26, Ultra 30.
      - Settings UI: Display tab picker + warning note + "Restart to apply" button. Scenario settings-graphics (renderer and restart overridden, renderer independent) with 4 goldens and screenshots.json entry. ScenarioRunner pins Low for every scenario (GraphicsRuntime.Pin).
      - Goldens re-recorded because the Display tab gained a row: settings/display, options/top, de, fhd, wide.
