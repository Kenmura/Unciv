- Notes: Found by the 2026-10-25 migration review (all three phases). Many ClientSnapshot fields have no event that updates them (own-city food stored, construction queue, buildings; own-unit health, movement, XP, current action, promotions; current tech; tile improvement/road/pillage; diplomacy status; spies; city health, puppet, razing) and events can be truncated (T209). T180's 'viewHash mismatch => snapshot' would then fire on nearly every command and T182's 'every client viewHash matches' fails. The snapshot also has no PopupAlerts/PendingDecisions, so a reconnecting player cannot see what blocks their End turn. Diffing the filtered DTO is safe (never GameInfo).
  - Implementation notes (Claude):
    - ClientSnapshot gains PopupAlerts (type, value, engine order) and PendingDecisions (the engine's PendingDecisions.For: kind, subject, resolvedBy, blocking, index) for the recipient only; both default to empty (not `required`, so existing constructions keep compiling). Snapshot wire message and whitelist test updated.
    - New SnapshotDiff/KeyedDiff (Net/Visibility/SnapshotDiff.cs): Compute(before, after) and Apply(mirror) over the filtered DTOs (civs, tiles, cities, units, diplomacy keyed; trades, notifications, alerts, decisions replaced whole; header fields). Added items carry their index in the new list; a full key Order is sent only when surviving items changed relative order (a unit moved tile). Apply recomputes ViewHash.
    - ViewDelta gains optional Diff (JsonElement) and ViewHash; ViewDeltaBuilder.BuildWithDiff(gameInfo, viewer, previousSnapshot, mark, events, seq, turnStatus) returns the delta and the new snapshot for the host to keep as the next 'previous'. Old Build (events only) unchanged. The host (T176/T180) must call BuildWithDiff per recipient after every accepted command, including server commands (RunAiTurn/BeginTurn), and send Diff; the host owns keeping the previous snapshot (and the TurnStatusDto, since the turn status is part of the hash).
    - Deliberate deviation: SERVER.md 2.4 amended (diff, not events, drives the mirror).
