As built (T226, Claude). Deliberate deviations from Kotlin (owner: parity relaxed):
- One More Turn (simultaneous games only; sequential keeps the Kotlin rule): `one-more-turn` is accepted from the server (the host's own command, e.g. the result of a vote the host tallied; the vote itself is host/server-side, not an engine command) or from the human whose civ is `TurnState.HostCivId` (new optional saved field, null = only the server), and never from a defeated civ. Others get `not-allowed`.
- Defeated humans: they already cannot issue player commands (`RequireActive` rejects them, except `EndTurn` for the sole-survivor case) and are played by step 2 of the round. New lobby setting `TurnState.DefeatedSeeFullMap` (default false = own view, i.e. what they had explored): true gives them spectator vision and reveals the map on defeat (the sole human of an offline simultaneous game always watches, as in single player, which keeps the T200 one-human == sequential hash test true) (`TurnState.DefeatedSeesWholeMap`, read by `HasSpectatorVision`, `RevealMapWhenDefeated` and `CivView.IsMapRevealed`; in simultaneous games the IsCurrentPlayer guard is gone from all three, per the T201 review note, outside them the Kotlin rule is unchanged). Both new fields are omitted from saves when default, so existing saves and hashes are unchanged. They are set by the host after `StartSimultaneousTurns` (no lobby/command writes them yet: wiring them to the lobby is a server task).
- `ForceEndTurn` (both modes) first settles each blocking decision the way the AI would (`Commands/Turn/DefaultDecisions.cs`, using new public wrappers in `NextTurnAutomation.Forced.cs`): free great person (first option), city production (`CityConstructionsAutomation`), research/free tech, policy, religion beliefs/pantheon, diplomatic vote (AI choices, state-based RNG), idle spies dismissed, a conquered city is puppeted (annex/destroy/raze as fallback). One decision at a time, list re-read after each, bounded. Each emits `decision-auto-resolved` (Participants audience, classified `ParticipantsOnly`). Not settled, left pending as before: `MoveAutomatedUnits` and anything that cannot be resolved (e.g. free great person without a city).
- Tests: `Commands/Turn/MultiplayerGameEndTests.cs`; `SimultaneousCommandTests.GameOverComes...` now sets a host civ.
