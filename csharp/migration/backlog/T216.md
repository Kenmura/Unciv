      Method: the exporter generates a Pangaea/Tiny map once (seeds 3, 11; Human+2 AI), pins each civ's start as a map StartingLocation (a HashMap<Tile,Float> sorted by score picks starts otherwise and Tile has an identity hashCode), strips units, saves the map (MapSaver.mapToSavedString; an existing file is kept, delete to regenerate). The C# test starts from the same file (T160 gameId replay, then GameId pinned the same way) and compares per turn. The start gameId is random in Kotlin but irrelevant once starts are pinned.
