        Deliberate decisions / deviations: (1) the command that completes the ended set (EndTurn, ForceEndTurn, SetController leave, Resign) also calls BeginResolving and returns the turn-resolving event, so no separate begin-resolving command exists and replay needs no extra entry (GameInfo.BeginResolvingIfAllEnded). (2) A simultaneous EndTurn/ForceEndTurn/AutoPlayTurn does not check the clock (ProcessEndTurn and BeginTurn carry Now). (3) SetController: server only, simultaneous Playing only (turn-resolving otherwise), major non-spectator civs, refuses a no-op, a defeated joiner, a key already in use, and handing the last human to the AI (not-allowed). A joiner's turn begins immediately (StartTurn), because AI civs only run StartTurn in step 2 and a joiner could never act or end the round otherwise; reclaiming a civ whose turn already began does not start it again. (4) GameInfo.RunAiTurn no longer runs StartTurn a second time for a civ whose turn already began (human handed to the AI or defeated during Playing): changed T200 behaviour, only reachable by the new hand-over. (5) Resign in a simultaneous game = SetController to AI (no EndPlayerTurn), refused with turn-resolving while resolving. (6) UndoEndTurn in a Sequential game is not-allowed. (7) AutoPlayTurn works in simultaneous games (marks ended); StartAutoPlay still needs TurnState.AutoPlayAllowed. (8) A civ that is the last non-ended one and gets defeated by another human's action is not detected until the next EndTurn/Force/SetController/Resign completes the check; the host's ForceEndTurn timer covers it (T177 should call ForceEndTurn for the rest).
