Fixed with AnyTrueAsync. The server's LobbySet-vs-start ordering is by design (host Start is a host API; clients cannot start). The T359 Gods & Kings pin (TimingSensitiveSettings) is removed; both tests run on the default BNW ruleset (40/40 repeated runs green, 3/20 red before).
